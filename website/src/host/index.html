Your Minecraft server, on your own machine.

Why pay for server hosting when you already have a powerful gaming PC? We certainly don't want to do that!
Lodestone Host is a free, open source server manager: start a server from a modpack, add mods from Modrinth, and play with friends without port forwarding.

Download for Windows Open the dashboard

Installs and updates with Lodestone CLI · Docker · All downloads

  • Vanilla, Fabric, Forge, NeoForge and Paper servers, plus modpacks from Modrinth.
  • Play together without port forwarding: share a server with an invite link - that's it.
  • Players get the right mods. Their Lodestone Launcher installs the mods your server needs and joins in one click.
  • Always private. Your servers and worlds stay on your machine, and we never see your data or sessions.
  • Users and permissions for everyone who helps run your servers.
  • API keys and a CLI for scripts, bots and agents.

Don't know networking or what Docker is? We got you.

  • No port forwarding

    Friends join with an invite link, through Lodestone Connect. No router settings, no IP addresses.

  • No Docker needed

    It runs on your computer as it is. One download installs it and keeps it up to date.

  • Java, sorted

    It downloads the right Java for each server, so you never have to.

  • Safe by default

    Only apps on your computer can reach it until you choose to share it.

Light enough to run beside your game

The core behind Lodestone Host waits for players on under 5 MB of memory and almost no CPU, so your PC is left for Minecraft. Here it is next to five other server panels on the same PC.

Measured on one Windows 11 PC (Ryzen 9 9950X3D) on 12 and 13 November 2026, with no Minecraft server running: medians of 5 starts, idle from 30 seconds after start for 60 seconds. Lodestone's core built from main; Crafty Controller 4.11.0, MCSManager 10.22.1, PufferPanel 3.0.9 and Pterodactyl 1.15.2 (its panel, MariaDB and Redis, without Wings) in Docker from their official images. AMP 2.8's Docker images need a paid licence, so it ran on Windows, next to Lodestone's core started the way Lodestone Host starts it.
