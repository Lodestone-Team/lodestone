Automate

Lodestone CLI

Install and manage Lodestone Host for headless servers.

Download → 
lodestone_cli server create --flavour fabric --name survival --wait
✓ survival is ready
lodestone_cli mods survival install fabric-api
✓ fabric-api installed
lodestone_cli server start survival --wait
✓ survival is running

Questions

Does Lodestone see our play sessions or data?
No. Everything including servers and worlds stay on your computers. When your friends join, our service helps the two computers find each other and hand the rest of directly between your machines - we don't do anything beyond that!
Are all of these completely free?
Yes. Every Lodestone app is free and open source, and always will be: no subscriptions, no paid tier, no ads. The code is on GitHub under the AGPL-3.0.
No, really. There must be a catch!
No catch. We're a group of tinkerers (🤓 nerds) who like building crap and playing Minecraft together, so we built the tools we've always wanted for ourselves. Say hi on Discord, or buy us a coffee on Ko-fi to support us.
